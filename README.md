# Customer Segmentation using K-Means Clustering

## 📌 Problem Statement
Businesses often have large customer bases but lack insights into customer behavior. This project groups customers based on income and spending patterns.

## 🎯 Objective
Segment customers into meaningful groups for targeted marketing strategies.

## 🧠 Approach
- Data preprocessing and feature selection
- Feature scaling using MinMaxScaler
- Elbow Method to determine optimal clusters
- K-Means clustering
- Cluster visualization
- Evaluation using Silhouette Score

## 📊 Features Used
- Income
- Spending Score

## 📈 Results
The model segmented customers into 4 clusters:
- High income, high spending → Premium customers
- High income, low spending → Potential customers
- Low income, high spending → Risky customers
- Low income, low spending → Budget customers

## 💡 Key Learnings
- Importance of feature scaling in distance-based algorithms
- How to choose optimal K using Elbow Method
- Interpreting clusters using data visualization

## 🛠 Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
